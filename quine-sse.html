Quine → S.S.E. URL

A quine is a program that prints itself. This tool verifies that property (it runs the code — only verify quines you wrote or trust), seals the source under a password into a quine-sse-v1. URL fragment (fragments never reach a server), and prints the URL as QR labels (Avery 5160, 3×10). The envelope reuses the repository's vetted PBKDF2/AES-GCM parameters; it is not byte-compatible with Paranoia Works SSE v3 — that format lives in the SSE app.
