Secret Space Encryptor · WebXDC

File & text encryption · AES · Serpent · Threefish · SHACAL-2 · Paranoia C4 · PRO features enabled
Files are sealed with the same password + algorithm and sent to the chat (or downloaded).
Algorithms — AES-256 and Serpent-256 are the free set. Threefish-1024, SHACAL-2 (512-bit key) and Paranoia C4-2048 (a cascade of Threefish → Serpent → AES → SHACAL-2) are the donation-tier ("PRO") ciphers from SSE.

SSE v2 compatibility — legacy payloads are detected by their version bits. SSE v2 uses the historical Skein-1024 + scrypt KDF and is accepted for decryption; new messages use v3.

AES variations — the modern Web Crypto format supports authenticated AES-GCM with 128, 192, or 256-bit keys.

SSE v3 format — byte-compatible with Secret Space Encryptor for Android/desktop: produces and opens the exact same encrypted messages (Base62 shareable links, Argon2id key derivation, EAX, LZMA, the Tnepres Serpent flavor). Verified against vectors generated from SSE's own source.

All cryptography runs locally in your browser in pure JavaScript — no server, no network, no telemetry.
