    CSS Zen Garden styles

    Fifty offline adaptations named for designs in the CSS Zen Garden. Pick one in the header or tap the dice button; each credit links to the original design. The original stylesheets target the Garden’s fixed HTML and image assets, so these preserve their names, designers and visual spirit without phoning home.

    Pages are stored locally in your browser (the USB stick, 2026 edition). Export the jar regularly — the browser is the stick now, and sticks get lost.

    Wikitext — the 0.8 syntax: == Heading ==, '''bold''', ''italic'', [[Page]], [[Page|label]], [[image:file.png|alt]], [[djvu:book.djvu|label]], [[tags:a,b]]. Full guide: Wiki Syntax.

    Index — every page in the jar

    The Java original keeps one .wiki file per page under public/docs/wiki; this rebuild keeps the same one-page-one-record model in browser storage and exports real .wiki text.

      Tags & tag tree

      Tag a page with the hidden link [[tags:topic,subtopic]] — exactly as in 0.8, where tags: and tagtree: are WikiLink namespaces that render nothing themselves.

      Bundled documentation — one page per *.md

      Every Markdown document in the repository (root *.md deep dives and viewer docs, plus docs/*.md) is converted to wikitext at build time by tools/wikiinajar/md2wiki.mjs and shipped as docs.json. Pages are virtual until you edit one — editing copies it into your jar, and your version wins on this device. Links between documents are real [[wiki links]].

      Media & DjVu library

      The Java extension serves local files from public/docs/image at /image/show/…. Here the same folder becomes an in-browser library: import PNG/JPEG/GIF/WebP/BMP/AVIF or .djvu/.djv, then embed with [[image:name.png|alt]] / [[djvu:name.djvu|label]]. Media stays on this device (it is not synced through the chat — files are too big for update payloads).

      Contacts (vCard)

      Wiki in a Jar doubles as an address book: it reads vCard (.vcf) contacts, and pages link them with [[vcard:Full Name]]. Import a .vcf file (or use Import… in the sidebar) to fill this book.

      Calendar

      Faithful to 0.8 (CalendarController → Month.loadEvents(), recovered 2026-10-14): one month at a time, holding contact birthdays (BDAY, recurring yearly) and pages whose title contains a date — 2026-11-05 Dentist is an event; a date in the body is not. Dated pages also auto-tag with their month and year.

      The grid is always visible, even with no events. Click a day to choose it. Bundled dated pages appear too; each event is an ordinary editable wiki page.
