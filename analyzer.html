WHAT THIS IS
A self-contained browser triage tool. It parses the DOS MZ header, calculates SHA-256 and entropy, identifies common embedded file headers, and displays printable strings.
WHAT THIS IS NOT
Ghidra is a desktop Java reverse-engineering suite. It cannot be converted into a faithful, secure in-browser HTML5 app merely by packaging it. Use Ghidra locally for full disassembly.
