(the resume prints the dates) or **[placed by context]** (undated on the resume; slotted by
era markers around it). On the variants: the live HTML page is the current register; the

of the resume page at all, and the fetch tools available here cannot spoof user agents — so the
live HTML (fully read Oct 6, 2026) is the sole current source and rules wherever they conflict.
