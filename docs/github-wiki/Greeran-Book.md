# The Greeran Book

The Greeran Book is an editorial, source-balanced biography of Steven Thomas Greeran. It distinguishes official records, self-published material, research-file findings, contextual sources, and private memory prompts; it is not a first-person autobiography.

## Read and build

- Source page: [`greeran-book.html`](https://github.com/shdwelf/Html5/blob/main/greeran-book.html)
- Research backlog: [`docs/greeran-book-ideas-backlog.md`](https://github.com/shdwelf/Html5/blob/main/docs/greeran-book-ideas-backlog.md)

## Opening sequence

The opening now uses an original, Myst-like sense of arrival without copied artwork: a foggy night landscape, a book gliding toward the reader, and a leather cover that opens into the first spread. It uses CSS and local markup only—no remote image or audio dependency. First visit plays the sequence; **Replay opening** runs it again. **Skip to the book**, Escape, and a reduced-motion path keep it accessible.

The opening is a first step toward the still-future explorable-age framing. It does not add narrative facts or change the evidence tiers. The future walk-through remains linked to the Glendora, ESGVROP, and UCSB 4DWM viewers.
