# The Greeran Book — ideas backlog & future formats

The parking lot for future editions, formats, and unresolved threads. Sorted by
kind. Companion files: `docs/ucsb-2001-first-quarter-research.md`,
`docs/esgvrop-deep-dive.md`. Book: `greeran-book.html` (ch. XV master timeline,
ch. XVI gaps & private prompts).

## Standing rules (from the author's instructions)

1. **Timeline first** — every event enters the master chronological register
   (ch. XV / `js/greeran-subsurface-data.js` TIMELINE) before it enters a
   chapter, so nothing goes into the narrative out of order.
2. **Classification system** — every row carries a tier: official / community /
   context / memory. Private recollection stays local-only until corroborated.
3. **The rolodex** — people, places, and entities get stable register ids
   (`js/greeran-subsurface-data.js` NODES) so chapters, apps, and the timeline
   can reference the same entity without drift.
