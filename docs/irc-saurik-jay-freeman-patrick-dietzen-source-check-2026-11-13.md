# Public source check: saurik's IRC, Jay Freeman and Patrick Dietzen

**Review date: 2026-11-13.** This is a bounded check of public, dated sources for `irc.saurik.net`, the related `irc.saurik.com` connection address, Jay Freeman (`saurik`), Patrick Dietzen, and the public `openmindpd` handle. It is **not** a recovered Saurik-network conversation, a complete server history, or an identification of an unknown IRC user. See the separate [EFnet `#pub` source map](historical-networks-and-source-leads-2026-11-13.md), [`#2600` check](irc-2600-shdwfear-enocia-source-check-2026-11-13.md), and [EFnet `#nsl` check](irc-nsl-shdwfear-shdwdruid-shdwelf-source-check-2026-11-13.md) for the earlier, distinct scopes.

**Finding:** Freeman documented his IRC server in 2003 and explicitly said in **2013** that he used the IRC nick **`saurik`** on `irc.saurik.com` *and* Freenode. Freeman identified Dietzen as a friend and former CyberUniverse colleague; Dietzen's public profile connects him to SaurikIT and uses `openmindpd` on LinkedIn/X. **No checked source establishes `openmindpd` as Dietzen's IRC nick, places Dietzen in a particular channel, or recovers a message by either man from `irc.saurik.net`/the Saurik network.** Do not transfer a nick across networks without source-specific corroboration.

## An actual dated IRC log hit — in Ubuntu's **`#ubuntu`** archive

The [original Ubuntu **`#ubuntu`** channel log for **2011-04-17**](https://irclogs.ubuntu.com/2011/04/17/%23ubuntu.txt) contains this message: `[03:59] <MarioMaster100> danieltux, is that you from irc.saurik.com?` (time as printed by the archive; its timezone was not independently established here). It is also line **224** in [a pinned, 1,500-line excerpt](https://github.com/jkkummerfeld/irc-disentanglement/blob/82ed04f9627a45d0d6f2ec3c8683c88eb408a0d5/data/train/2011-04-17.train-c.raw.txt#L224); the [dataset's own data README](https://github.com/jkkummerfeld/irc-disentanglement/blob/82ed04f9627a45d0d6f2ec3c8683c88eb408a0d5/data/README.md) identifies its `train` material as Ubuntu IRC logs. The pinned excerpt's Git blob ID is `1168360a3e78f8d0ec73aaaf68bc44ce08dca4d2`; multiple search hits for the identical blob are **copies, not independent witnesses**.

This establishes **only that one user asked a question about the Saurik address in Ubuntu `#ubuntu`**. It does **not** verify `danieltux`'s identity, any earlier meeting on the Saurik network, an answer from that user, or a message by Freeman/Dietzen. The channel-attributed original makes this a useful *disambiguation*, not a Saurik-channel transcript. No full third-party log, incidental personal information, or private conversation was copied into this repository.

## Archive coverage and negative-result limits

- [Netsplit's **Saurik** statistics page](https://netsplit.de/networks/statistics.php?net=Saurik) says its network entry was registered **July 2015**, regular connections stopped from **March 2021**, and it is classified **historic**. Its graph says `ERROR: Failed to get valid data for network 'Saurik'!`. This is a **collector's observation window**, not the server's start date, proof that it never returned, or message history. Direct server/channel pages were not reliably readable in this pass.
- [Archive Team's IRC-log directory](https://wiki.archiveteam.org/index.php/IRC/Logs) and [its inspected public irclogger channel index](https://archive.fart.website/bin/irclogger_logs) list selected loggers/channels, **not** the full history of every IRC server. The inspected channel index did not list `iphone`, `android`, `theos`, or `winterboard`. Guessed [IRC Driven `iphone`](https://www.ircdriven.com/network/Saurik/channel/iphone/log/), [`android`](https://www.ircdriven.com/network/Saurik/channel/android/log/), and [`theos`](https://www.ircdriven.com/network/Saurik/channel/theos/log/) log URLs returned **404**. None is evidence no independently held log exists.
- The [IRC Memory Lane production-network listing](https://tools.tornevall.net/irc/api/networks?source=production) includes **IRCNet and TornevallNET**, not Saurik; it cannot yield a meaningful negative search for this network. On review, GitHub code searches for `"irc.saurik.net" extension:log`, `"irc.saurik.com" extension:log`, and `"openmindpd" extension:log` each returned **zero indexed files**. The unrestricted query `"irc.saurik.com" "#theos"` instead returned **six** files, including [an iRET README thanking the channel](https://github.com/S3Jensen/iRET/blob/8bfe376e6ccfd4219c9d405dd8f6c0226e2ef26c/README.md) and [an XMPP logger README crediting help there](https://github.com/BrianHenryIE/XMPPFrameworkLogger/blob/ac8427ac72850cfe4b7015cf586d9722f99a5c9a/README.md): references to a channel, **not original chat logs**. Searches with `"irc.saurik.com" "openmindpd"` also returned zero indexed files. Together with the bounded public web searches, none produced an original Saurik-channel message by a target. Index coverage is incomplete; this was **not** a scan of all historical client/bot files.
- Fetching `http://irc.saurik.net` as a web page did not expose a usable archive. **An IRC endpoint is not an HTTP transcript**: neither a failed HTTP fetch nor a present-day IRC connection could recover years of old messages. No direct IRC socket connection was attempted in this check. Treat search-indexed references to a same-spelled nick on **Freenode** as separate from Saurik-server logs: a join event is not speech, and a matching nick across networks does not establish a person's identity.

**Next evidence gate:** an owner-provided, rights-cleared `irc.saurik.com`/`irc.saurik.net` **channel-specific** client or bot log, with approximate dates and a verified network/session header, would allow a bounded check for `saurik`, `openmindpd`, or a separately evidenced Dietzen nick. Preserve the original bytes and hash, source owner/capture method, timezone and neighboring context; distinguish `NAMES`/`JOIN`/`QUIT` from `PRIVMSG`/action, and do not assume a nickname proves a person's identity. Keep any private raw log and genuinely recovered private chat in **owner-controlled Drive**, not this public repository. No private Saurik-network conversation was recovered in this review, so there is nothing to upload.
