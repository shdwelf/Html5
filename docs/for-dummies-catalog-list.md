## How to reproduce in the terminal

1. Open the **SRU directory** tab in `apps/z3950-sru-gopher-terminal.html`.
2. Leave the query as `For Dummies` or enter a more specific title.
3. Choose Library of Congress or DNB.
4. Press **Search**.
5. If a browser blocks the cross-origin request, use the PHP/YAZ adapter or open the linked WorldCat catalog records directly.

WorldCat is a discovery/catalog source here, not an unrestricted anonymous Z39.50 endpoint. OCLC's Z39.50 service requires authorized credentials for production cataloging access.
