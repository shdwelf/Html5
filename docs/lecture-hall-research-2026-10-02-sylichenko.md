# Crow continuation — the first solver's published method, 2026-10-02 (second pass)

The morning pass identified SECOM, rebuilt the exact disrupted transposition,
and rejected the opening-line candidate. This pass follows the one public
thread the challenge page leaves hanging: its first listed solver, **Oleksii
Sylichenko (Ukraine, 8 February 2023)**, publishes code on GitHub as
**asilichenko** — and that account is a primary source for his *method
discipline*, even though it contains nothing about the Crow itself.

Deltas: lecture hall 30 → 31 records, CyberChef 369 → 372 recipes,
`tools/secom_probe.py` gains a scoring ladder, a structural histogram check and

## 1. What the resource actually is

<https://github.com/asilichenko> — profile name "Oleksii Sylichenko", located
in Ukraine. The relevant repository is
[`enigma`](https://github.com/asilichenko/enigma): *"Enigma machine simulator +
cipher breakers"*, LGPL v3, four Maven modules (`enigma-machine`,
`enigma-setting`, `enigma-utils`, `hill-climbing`). Its README documents a
Sullivan–Weierud hill-climb (crediting the cryptocellar paper directly) with
several measurable engineering decisions:

- **Integer IoC** — `IocFitness` scores `sum(h[i]^2)` instead of
  `sum(h[i](h[i]-1))/(N(N-1))`: the constant parts cannot change the ranking,
  so the hot loop needs no division (and the README notes `X*X` beats
  `Math.pow(X,2)`).
- **Fitness ladder** — `PlugboardService` switches fitness by plug count:
  unigram for pairs 1–4, trigram for 5–9, tetragram for the last (source
  constants `MIDDLE_STAGE_THRESHOLD = 4`, `LAST_STAGE_THRESHOLD = 9`); IoC
  alone suffices for long messages.
- **Precompute** — with wheels/rings/starts fixed, encipher the whole alphabet
  at every text position once (`int[steps][26]`); each plugboard trial then
  costs lookups only: `plain = P(E_k(P(cipher)))`.
- **Stage-1 calibration** — before any search is trusted, score a same-length
  sample text in the traffic language and derive the candidate and garbage
  thresholds from it.

Equally important is what the repository does **not** contain: no SECOM code,
no Crow ciphertext, no solution file. His n-gram resources are German
(`de/unigrams…tetragrams.txt`), underlining that the language model must match
the traffic — the Crow is English. Code provenance must not be stretched into
solution provenance; the solve itself remains unpublished, and the page (last
changed 5 September 2026, after Daisuke Kondo's second solve) still withholds
plaintext and key.

Other repositories on the account (`simulated-annealing`,
`ant-colony-optimization`) show general metaheuristic interests but carry no
cipher material; they were reviewed and not used.

## 2. What was ported, with executable controls

### CyberChef (369 → 372)

- **`secomExact`** — full SECOM encrypt/decrypt with the authoritative
  triangular disruption, byte-for-byte the algorithm of
  `tools/secom_probe.py`. Control: the official worksheet phrase and plaintext
  reproduce the published 105-digit vector, and the vector round-trips. The
  rejected Crow candidate decrypts to the same recorded letter soup
  (`OYSASOXVEMSA 0OYVEAAPSFPSMSFITOTSHAOSHSS…`) — the exact model, not a
  "repaired" one.
- **`iocFitness`** — the measuring instruments: Friedman IoC, the Σh² integer
  shortcut, English chi-squared, compact bigram log-score, with the Stage-1
  calibration rule printed in the output.
- **`plugboardHillClimb`** — the precompute + ladder inner loop in the
  browser. Control (in `test/cyberchef-field-museum.test.ts`): a 274-letter M3
  ciphertext with Stecker `EN RT OS AI` is generated by the `enigmaM4` recipe
  (Beta/A/thin-B ≡ wide-B M3, the morning pass's own control) and the climb
  recovers `AI EN OS RT` and the full plaintext. The port is honest about its
  reductions: unigram→bigram instead of unigram→trigram→tetragram, and
  wheels/rings/starts held fixed — the inner loop, not the whole keyspace
  walk.
- New recipe pack *"Sylichenko Enigma Lab — Hill-Climbing the Plugboard"*;
  `secomExact` also joins the field-cipher pack.

### The probe (`tools/secom_probe.py`)

- **Transposition-invariant histogram.** Columnar transposition permutes
  digits but never changes their counts, so the Crow histogram **is** the
  checkerboard-encoded plaintext histogram plus ≤ 4 pad zeros:

  ```text
  2:144  3:116  8:88  5:56  7:46  6:45  4:40  1:33  0:23  9:9
  ```

  Any proposed solution must reproduce this multiset exactly — a free
  necessary condition that costs one pass over 600 digits, long before full
  re-encryption. (The verifier recomputes these numbers from the ciphertext
  constant so the record can never drift.)
- **Calibrated scoring ladder.** Per Stage-1 discipline, an English sample and
  a wrong-phrase null decrypt bracket the thresholds
  (`bigram ≥ −0.091`, `chi² ≤ 335.0`, `IoC ≤ 0.1177` on this run).
- **New negative-control finding.** SECOM's checkerboard deliberately maps
  frequent digits onto E,S,T,O,N,I,A, so *wrong-key output flatters unigram
  and bigram models*. One 20-letter hint window (`UTTHREETIMESTOUNVEIL`,
  bigram +0.016) slipped past the n-gram rungs and was exposed only by
  Friedman IoC (0.1396 against English ≈ 0.067). For SECOM candidate testing
  the IoC rung is load-bearing — the reverse of the usual Enigma situation,
  where IoC is the coarse filter and n-grams decide.
- **Scan result.** All **111** documented hint-derived candidates — 8 named
  phrases (the hint lines, the crow sentences, the re-run opening line) and
  103 sliding 20-letter windows over the concatenated six-line hint — are
  **REJECTED** under the exact published algorithm. The title line
  `THETOWNILOVEDSOWELL` (19 letters) stays excluded rather than padded. A
  symmetric control phrase also exposed a documented SECOM edge case: an
  even-digit chain cycle cannot derive two transposition widths.

The negative result is the research product. The phrase remains unknown, and
nothing here reconstructs, claims or implies Sylichenko's private solution.
