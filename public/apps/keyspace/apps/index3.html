Read-only EVM NFT / ERC-20 metadata · Local JavaScript modules

Inspect token facts, then choose whether to fetch metadata

Enter an EVM RPC URL, NFT contract address, and token ID to read ERC-721 or ERC-1155 details on-chain. The app checks the expected chain ID and uses read-only eth_call. Off-chain JSON is a separate, opt-in request. A token URI does not mean the referenced JSON or image is on-chain. No wallet connection, signing or transfers.

Lookup

Works best with ERC-721 and ERC-1155 contracts on Ethereum-compatible chains. Optional ERC-20 name/symbol/decimals/totalSupply reads do not verify identity or backing. IPFS and Arweave pointers use public gateways only after separate consent. HTTPS only, 12-second read timeout, 1 MiB JSON limit; no automatic external media.
