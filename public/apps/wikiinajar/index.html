    Index — every page in the jar

    The Java original keeps one .wiki file per page under public/docs/wiki; this rebuild keeps the same one-page-one-record model in browser storage and exports real .wiki text.

      Tags & tag tree

      Tag a page with the hidden link [[tags:topic,subtopic]] — exactly as in 0.8, where tags: and tagtree: are WikiLink namespaces that render nothing themselves.

      Media & DjVu library

      The Java extension serves local files from public/docs/image at /image/show/…. Here the same folder becomes an in-browser library: import PNG/JPEG/GIF/WebP/BMP/AVIF or .djvu/.djv, then embed with [[image:name.png|alt]] / [[djvu:name.djvu|label]]. Media stays on this device (it is not synced through the chat — files are too big for update payloads).

      Contacts (vCard)

      Wiki in a Jar doubles as an address book: it reads vCard (.vcf) contacts, and pages link them with [[vcard:Full Name]]. Import a .vcf file (or use Import… in the sidebar) to fill this book.

      Calendar

      The 0.8 Calendar view surfaces dated PIM entries; this rebuild lists contact birthdays (BDAY) plus any page lines beginning Date: YYYY-MM-DD. Labelled as an adaptation in the deep dive — the original calendar semantics are still being researched.
