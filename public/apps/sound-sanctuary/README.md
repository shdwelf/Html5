# Sound Sanctuary

Restored from complete self-contained snapshots already present in this repository. Original source files are preserved byte-for-byte; see provenance.json for exact input/output SHA-256. The extensionless AURA /src/main.tsx placeholder is NOT the app.

- Inline React, DSP, styles and assets; no remote fonts, analytics, runtime CDN or app-level uploads.
- Browser audio experiments, NOT certified THX, Dolby, Bose or IMAX technology, reliable acoustic active noise cancellation, or hearing protection. Start at low volume; headphones recommended. Stop on feedback.
- Playback and microphone access require your interaction. Android grants audio only to the current matching allowlisted packaged audio origin, never cameras or arbitrary network pages.
- Use the app's explicit preset/HTML export controls. Android uses the system Files picker for Blob exports up to 64 MiB and reports success only after read-back verification. A browser download request is not proof of a saved file. Choose an on-device destination to avoid a cloud provider.
- Runtime state is not automatically backed up; self-HTML exports are not guaranteed runtime-session backups. Uninstall, clearing app data, closing/navigating away and an OS process kill can lose unsaved changes. Keep an independent exported copy of your research/settings. Audio file import is user-selected, not a bundled recording.
