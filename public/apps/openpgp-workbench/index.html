v4 RSA signing/certification primary + same-size RSA encryption subkey. Default 3072 bits; opt-in sizes through 16384 bits. Both private packets are protected with AES-256 and iterated SHA-256 S2K (0xFF). No AEAD, v5/v6 or post-quantum output.

Source-informed targets: OpenKeychain, PGPony Android/iOS and KDE Kleopatra/GnuPG. This browser tool is not a device compatibility certification. Prefer a dedicated reviewed client for high-value identities. Nothing is generated until you submit your own User ID and passphrase.

Supply a name or an email. User IDs are public, self-asserted claims. Never enter a wallet recovery phrase.

At least 12 characters; use a strong unique passphrase. No strength guarantee or passphrase recovery. The passphrase fields are cleared when generation starts.

Larger is not automatically safer. Slow generation, larger files and client limits can outweigh the benefit. 16384 bits is a resource cap, not a compatibility guarantee.

Large RSA is an advanced opt-in. Both key packets use the selected size. Generation can take many minutes, particularly on phones. Up to 8192 bits uses native Web Crypto, which cannot be stopped once started. Above 8192 uses a local isolated worker with the existing OpenPGP.js prime search enabled by a narrowly scoped dispatch patch, not native generation; Clear terminates that worker (20-minute resource limit). A real 16384-bit browser trial reached the 20-minute limit without completing; that generation choice is experimental, not verified successful browser generation. Public imports through 16384 bits and native Node generation are tested separately. Your client may refuse very large keys. Test with a synthetic identity before relying on them.

No key exists here until you generate one. Generation is random, not derived from an account or mnemonic.

Public-only keyring

Import v4 RSA public certificates (2048–16384 bits) or v4 legacy Ed25519/Curve25519 certificates. Both concatenated armor blocks and multiple certificates in a single block are read. Limit: 1 MiB and 32 certificates. Secret packets, photo IDs, other profiles, mixed content and unsupported packets are refused.

A matching fingerprint only compares bytes you supplied. Verify it over an independent trusted channel. Bulk imports without this field remain identity-unverified. Self-certification checks do not assign owner trust or audit every User ID/subkey.

    !

    Know what this does not prove

    MDC checks message integrity, not who sent it. This app does not authenticate sender identity, verify signatures, or replace an independently reviewed secure-messaging client.

    i

    Scope: classic passphrase text tools plus export-only RSA key creation and a public-only keyring. Public-key message encryption/decryption, signing UI, attachments, secret-key import, hardware cards, owner trust and modern AEAD output are not included. Processing is local; no app-level upload. Only validated PUBLIC certificates may be remembered after explicit opt-in. Android Save opens the system Files picker and confirms success only after write/read-back verification; browser downloads are requests, not proof of a saved file.
