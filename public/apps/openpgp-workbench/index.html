    Local wordlist-assisted private-key recovery

    For your own protected OpenPGP/GPG private key: rank a small wordlist against a remembered hint and optionally add bounded typo variants. OpenPGP requires the exact passphrase; fuzzy distance is only a way to choose guesses, never a partial unlock. This is not public-key cracking or message/file recovery.

    Use only a trusted, isolated device and an unmodified local copy of this app. Private-key input and guesses are sensitive: browser extensions, other same-origin apps, keyboard/clipboard tools and screen capture are outside this tool's protection. No keyserver, metasearch, cloud dictionary, upload, storage, automatic export or recovery guarantee. Keep the original protected file unchanged and backed up.

    One complete ASCII-armored certificate. Bounded profiles: v4 RSA-2048–16384, v4 legacy Ed25519/Curve25519, v6 Ed25519/X25519; up to 16 secret packets. Every packet must be AES-protected with iterated salted SHA-1/SHA-2 S2K and SHA-1 integrity or standard AEAD. Argon2, unprotected/stub/hardware keys, unsupported/mixed packets and old 16-bit checksums are refused; nothing is silently dropped or weakened.

    Leading/trailing spaces, case, Unicode form and a UTF-8 BOM are retained in guesses. CRLF separates lines; blank lines are ignored and exact duplicates removed. Empty passphrases, controls, invalid Unicode, over 128 characters / 256 UTF-8 bytes per candidate or hint are outside this profile. Files with malformed UTF-8 are refused, not repaired.

    Ranking compares NFC-normalized, lowercase Unicode characters using insertion, deletion, substitution and adjacent transposition distance. It never changes original wordlist bytes. With no hint, keep wordlist order. Fuzzy filtering may exclude the correct passphrase; compare the preview/count.

      Know what this does not prove

      MDC checks message integrity, not who sent it. This app does not authenticate sender identity, verify signatures, or replace an independently reviewed secure-messaging client.
