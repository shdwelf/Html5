Classic compatibility profile

v4 SKESK · iterated-and-salted SHA-256 S2K (coded count 0xFF) · AES-256 · SEIPD v1 with MDC. AEAD output is disabled.

!

Know what this does not prove

MDC checks message integrity, not who sent it. This app does not authenticate sender identity, verify signatures, or replace an independently reviewed secure-messaging client.

i

Version 1 scope: text-only, passphrase-based classic OpenPGP. Public-key workflows, signing, file attachments, and modern AEAD profiles are not included. Processing is local to this browser tab; there is no app-level data upload or persistence.
