This page is not a re-implementation. It runs socal-calc/core/*.c transpiled by calc/tools/c2js.py into js/socal-core.js — the same source sdcc builds for the Z80 and TIGCC builds for the 68k models. make -C socal-calc test diffs this build against the gcc build for all three devices and requires every framebuffer hash to match.

Geometry is quantised to 1/2000° (~28 m worst case) from socal-subsurface.xdc; terrain comes from the app's own elevationAt() reworked in fixed point, mean error 2 m. Routes are 5–15 km generalizations. Not for excavation — call 811 before you dig.
