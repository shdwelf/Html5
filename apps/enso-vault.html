About & Notes

Single-file, offline-capable HTML5 app. Embeds the official BIP-39 English 2048-word list with precomputed syllable counts for real 5-7-5 haiku composition.

  • Ensō Forge: seeded randomized brush ensō → PNG; Ensō ID encodes all parameters (Worms-terrain-style seed).
  • Haiku Wallet: valid BIP-39 entropy + checksum, BIP-44/84 paths, batch mining, spell-check, forging animation, collectible IDs.
  • Vault: AES-256 (WebCrypto AES-GCM) encrypted save/export/delete + encrypted-cookie persistence, key derived from Ensō ID + passphrase (PBKDF2).
  • Terminal/IRC: command shell + IRC over WebSocket gateway.
  • Waves & Market: embedded Waves Lite client + live price table.

Security warning: This is a demo/educational tool. Mnemonics are generated with crypto.getRandomValues but you should never store real funds in a browser-generated, cookie-persisted wallet. Verify any seed in trusted offline software before use.
