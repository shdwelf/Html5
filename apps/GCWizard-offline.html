Your Starred Favorites

Caesar Cipher (ROT-N)

Coordinate Converter

Universal parser for Decimal Degrees (DD), Degree Minutes (DDM), Degree Minute Seconds (DMS), and UTM.

Morse Code Translator

Decodes dots and dashes, plays audio sounder beeps, visual flash simulation, and reference chart.

Word Value / Letter Values

Calculates character sums (A=1..Z=26, reverse A=26..Z=1, ASCII values) and letter counts.

Mystery Formula Solver

Assign variables (A=5, B=12), evaluate mystery coordinate formulas, and keep geocache notes.

Vanity Text Miner

Brute-force search for strings matching a target pattern using configurable charsets, hash modes, and live speed stats.
