WHAT THE MAP IS

The globe uses the repository's low-resolution Natural Earth country-outline GeoJSON for geographic context only. The colored route is a viewer-authored story index. Numeric coordinates are not displayed or exported as claimed historical locations.

The submarine is a deliberately generic outer silhouette. X-ray mode shows a generic inner volume only; it does not map compartments, machinery, weapons, acoustic systems, or an engineering layout. “Profile relief” is a decorative synthetic curve, not bathymetry.

ARCHIVAL / GAME IDENTIFICATION

Internet Archive has separate 1987 and 1990 DOS listings for The Hunt for Red October and a separate Grandslam manual record; the app keeps them distinct. Shadow President (1993 DOS) is the identified presidential geopolitical/nuclear-command simulator, not an FPS and not a source for this viewer’s fictional submarine anchors. The original manual should be consulted before asserting detailed launch or retaliation mechanics.

TIME REPRESENTATIONS

Story chapter is an ordinal viewer index. UTC, local time, Unix time, and Julian Date show the current wall clock only. None is presented as a date or timestamp for the fictional vessel.

XENA EXPORT

The XML uses the Xena default package wrapper and the NAA Binary object namespace to Base64-wrap the exported VRML. It preserves the model bytes; it does not normalize the fictional scene into a more open 3D model format. The sidecar JSON records the checksum and provenance limits.
