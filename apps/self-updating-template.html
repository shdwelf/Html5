About this file

This is a single-file HTML5 app that updates itself by periodically fetching a newer copy of its own HTML from a URL you configure, then hot-swapping the page when you confirm.

Everything runs offline once loaded — there's nothing else to download. Cached state lives in localStorage under the key self-updating-template.
