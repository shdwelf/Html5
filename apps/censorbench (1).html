📬 The Postman's Sort — Robert Ramey

First published in the C Users Journal (August 1992). Robert Ramey — MS Operations Research, UC Berkeley (1971) — is also the author of the Boost Serialization Library and a contract software developer based in Santa Barbara, California.

After graduating from UC Berkeley and serving 18 months in the military, he traveled to Ecuador where he founded a data processing company that is still in operation today. Returning to California in 1986, he focused on technical software development, producing the Postman's Sort and Boost Serialization Library among other projects.

How It Works

  1. Analyze the sort key structure (fields, types, character sets, lengths)
  2. For current key position, allocate distribution buckets based on key attributes
  3. Distribute all records into buckets by most significant part of the key
  4. For each non-empty bucket, advance to next key position and recursively distribute
  5. When a bucket contains one record or key is exhausted, output the record(s)

Key insight: For alphabetic fields, 2 bytes at a time with only 703 buckets (1 + 26 × 27). For decimal fields, 3-4 bytes at a time. The function sort() receives a sublist, then plan() and allocate() reserve memory, dist() distributes among sublists, and dsort() recurses on each.

Key Characteristics

  • Non-comparative: O(cn) time where c = key size × number of fields. Keys are never compared against each other.
  • Top-down (MSD): Processes most significant digit/field first, enabling early termination for partially sorted data.
  • Hierarchical: Exploits structural hierarchy (postal codes: country → state → city → route).
  • Adaptive buckets: Allocates exactly the needed buckets per field type rather than fixed 256 or 65K.
  • Multi-field sorting: Naturally handles records with varying numbers of fields and key types.
  • External sort capable: The 2005 Penny Sort winner sorted 15 GB using only 2 SATA drives on a $951 system.

Sort Benchmark Competition

The Sort Benchmark (sortbenchmark.org) was originally the Datamation Sort, first defined by Jim Gray et al. in 1985. It evolved into MinuteSort (1994), PennySort (bang-for-the-buck), GraySort (100TB+), JouleSort (energy), and CloudSort.

pdqsort
Orson Peters
Pattern-defeating quicksort. Improvement of introsort used in Boost.Sort and Rust's standard library.

David Musser (1997)
Hybrid of quicksort, heapsort, and insertion sort. Used in C++ std::sort implementations.

Francisco Tapia
Stable sort fast with random or nearly sorted data. Uses N/2 additional memory.
American Flag Sort
McIlroy, Bostic, McIlroy
In-place MSD radix sort. Similar principle to Postman Sort but optimized for ASCII strings.
Burstsort
Sinha & Zobel (2004)
Cache-efficient string sort using burst tries. Extends MSD radix principles.
