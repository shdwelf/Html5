# Armstrong–Madison Cipher Lab · source-review build

Preserves the user's **20 February 1808** XDC workbench and its 18 original
sections, adds a default **Verified research** reader, and repairs working-key
editing and exports. This is an offline investigation aid, **not a verified
complete decipherment**. The separate 30 August 1808 THE=972 postscript is not
substituted for February.

## Open or rebuild

- Browser library: `/apps/` → **Armstrong–Madison Cipher · Source Review**.
- Direct workbench: `/apps/armstrong-madison/index.html`.
- Standalone evidence reader: `/apps/armstrong-madison/research.html`.
- Installable ZIP/Webxdc: repository-root `armstrong-madison-cipher.xdc`.
- [Research review](../../docs/armstrong-madison-cipher-review-2026-11-17.md)
  and [evidence/provenance](../../docs/research/armstrong-madison-1808/).

```sh
npm run build:armstrong-madison
npm run check:armstrong-madison
npm run test:armstrong-madison
npm run build:app-catalog
npm run check:html5-offline-launcher
```

The builder uses the repository's vendored ZIP implementation. No downloaded
solver, network request or runtime package install is needed by the app or the
build. The tests require the locked Node/Chromium development dependencies.
Build checks fail on an altered input, patch-anchor drift, extra public files
or stale generated bytes; they do not rewrite outputs when `--check` is used.

## What is retained

`input/armstrong-madison-cipher.xdc` is the exact supplied archive, despite its
original `.xdc.xml` suffix. SHA-256:
`9bd424b0c8349f30d6fb9872eab68d4db64281a689a3a5b0e4e0aeb5b80e7d96`.
Its only entries are HTML, manifest and decorative artwork. The complete
workbench/artwork license was not supplied; no general redistribution clearance
or source-to-binary authentication is invented. See `THIRD_PARTY_NOTICES.txt`.

The original imported narrative tabs stay available but are **not newly
source-certified**. Use the new reader for the checked findings, source levels,
quoted excerpts and reproducible audit. The normalized editorial text has
365 complete numeric readings and one damaged prefix. Applying the exact
56-entry AFIO claim labels 130/365 (35.6%); coverage is not correctness.
Graphical descriptions are not decoded glyphs. Manuscript scans, full graphical
collation, an independent key and a complete plaintext remain missing.

## Guess handling and exports

- Solver edits start in memory. No startup storage read/write or chat operation.
- Explicit device save/load/forget uses only this app's current and legacy
  working-key entries. Storage is unencrypted and may be cleared/evicted.
- JSON import is bounded and validated. Labels are displayed as text, not HTML.
  Limits: codes 1–1900, 80 characters per label, 96,000 exported JSON characters.
- Webxdc sharing/history loading additionally requires the visible checkbox and
  a button press. Incoming maps are validated and buffered, not automatically
  merged into or substituted for local work. Revoking the checkbox clears the
  pending buffer and ignores subsequent arrivals; it cannot retract chat history.
- The new reader's audit key is independent of the original solver key. It starts
  with the AFIO **claim** to make the published-key audit reproducible; it is not
  a silently loaded working hypothesis.
- Portable HTML and in-browser XDC exports include the embedded reader and
  notices/report but **exclude working guesses**. Export JSON separately to
  keep them. Runtime XDC has five root files; the repository-built XDC includes
  the optional icon, separate reader and bounded evidence files as well.
- Browser exports report only a download request. If the existing Android
  `Html5LocalFiles` adapter is present, save success requires matching byte count
  and SHA-256; cancellation/failure is not reported as success.

The source reader is embedded in an opaque-origin sandbox. Both documents
restrict connections with CSP and contain no external automatic resources.
References are explicit links; offline hosts may block outbound navigation.
No microphone, network or private-profile allowlist changes are needed.
Desktop Chromium, Webxdc API mocks and ZIP round trips are not physical
Delta Chat or Android-device certification.
