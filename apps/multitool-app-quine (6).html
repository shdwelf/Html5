What is a Quine?

In computer science, a quine is a non-empty program that takes no input and directs the operating system to output a copy of its own source code.

Because this React/Vite application compiles everything down to static HTML, styles, and scripts, clicking "Download HTML5 Quine" will instruct the running app to read its own active DOM tree, package it, and download it as a single local HTML file!

Opening the downloaded file locally on any laptop or phone runs all ciphers, calculators, games, and ciphers fully offline!

Native Desktop App Bundle

Do you want to run this portal as a double-clickable desktop application without address bars or browser frames?

Clicking below will download both the HTML5 Quine app and a custom Python launcher script (`launcher.py`). Place them in the same directory and double-click the script to run it as a local app!

launcher.py Source Code
import webbrowser
import http.server
import socketserver
import threading
import os

PORT = 8080
HTML_FILE = "multitool-app-quine.html"

class Handler(http.server.SimpleHTTPRequestHandler):
    def translate_path(self, path):
        # Always serve the single file quine for any local request
        return os.path.abspath(HTML_FILE)

def start_server():
    with socketserver.TCPServer(("", PORT), Handler) as httpd:
        print(f"Serving locally on port {PORT}")
        httpd.serve_forever()

if __name__ == "__main__":
    # Check if the HTML app exists in the same folder
    if not os.path.exists(HTML_FILE):
        print(f"Error: {HTML_FILE} not found! Please place it in the same directory.")
        input("Press Enter to exit...")
        exit(1)
        
    # Launch local server in background thread
    server_thread = threading.Thread(target=start_server, daemon=True)
    server_thread.start()
    
    # Open the native default browser to our app
    webbrowser.open(f"http://localhost:{PORT}")
    print("Desktop application launched! Close this terminal window to stop.")
    
    # Keep main thread alive
    try:
        while True:
            pass
    except KeyboardInterrupt:
        print("Stopping server...")
