Standalone EVM NFT Viewer · No external JS libraries

View NFT details directly from chain

Enter an EVM RPC URL, NFT contract address, and token ID to read ERC-721 or ERC-1155 details on-chain. The app calls JSON-RPC directly using eth_call, then resolves metadata from the returned token URI.

Lookup

Works best with ERC-721 and ERC-1155 contracts on Ethereum-compatible chains. If metadata uses ipfs:// or ar://, the viewer converts it to a public gateway URL.
