What is a Quine?

A quine is a program that takes no input and produces a copy of its own source code as its only output. This application is a self-replicating single-file HTML application — it reads its own running DOM (which contains ALL of its JavaScript, CSS, and HTML inlined) and outputs an identical, fully-functional copy of itself.

The downloaded .html file is a perfect clone. Open it in any browser — offline, no server needed — and the entire AURA SoundStudio Pro with all THX, Dolby, Bose, IMAX, and Real3D audio processing runs identically. It can then download itself again. ∞
