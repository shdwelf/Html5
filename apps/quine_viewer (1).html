How it works

1. Load a ZIP containing a React+Vite+Tailwind project (with package.json, src/, etc.)
2. Click ⚡ Compile to HTML5
3. The compiler finds your entry point, collects all JSX/TSX/CSS source files, and generates a single HTML that:
  • Loads React 19 + ReactDOM from esm.sh CDN via import maps
  • Uses @babel/standalone to transpile JSX/TSX in-browser
  • Injects Tailwind CSS v4 Play CDN for utility classes
  • Inlines all source code and images as data URIs
4. Preview and download the result — one file, works offline after first load.
