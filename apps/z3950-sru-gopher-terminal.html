Catalog crossroads

Z39.50 for native library retrieval, SRU for HTTP/XML catalogs, and Gopher for lightweight text discovery. This static Webxdc-safe edition links to public endpoints without pretending a browser can open TCP/210 or TCP/70 directly.

SRU targets

SRU is Search/Retrieve via URL: CQL in, XML out. Click a target to open its Explain or search URL. The Library of Congress and DNB publish current endpoint documentation.

Gopher targets

Gopher uses a line-oriented menu protocol over TCP/70. Modern browsers generally do not implement it, so each entry includes the native URI plus a Floodgap HTTP gateway where available.

Why inline is different

Gopher and Z39.50 are not HTML transports. A Webxdc cannot open arbitrary sockets, and an HTTP page cannot safely turn itself into a universal proxy. This artifact keeps the directory and links inline, while the PHP companion performs allow-listed server-side Z39.50 work.

ZShaolin → HTML5 bridge

ZShaolin is an Android GNU/Linux terminal build framework from dyne/ZShaolin. Its native Android toolchain, shell, SSH, Git, Lynx, and terminal programs cannot be copied into a browser as binaries, but its terminal workflow can be represented safely as an inline HTML5 command surface.

This bridge does not execute shell commands or fetch arbitrary GitHub content. It provides catalog-safe commands and links to the upstream source.

Protocol boundaries

Z39.50 ASN.1/BER association, Bib-1/RPN search, result sets, Present, MARC syntax.

SRU HTTP GET/POST, CQL, XML response, Explain, paging with startRecord and maximumRecords.

Gopher TCP menu request, tab-separated directory lines, dot-terminated responses, port 70.

WorldCat remains a credentialed Z39.50 service: zcat.oclc.org:210/OLUCWorldCat. Use authorized OCLC credentials; do not embed them in this app.

Research notes

UCSB Davidson Library’s Cylinder Audio Archive historically used Z39.50 against Aleph, but migrated to Alma/SRU. Its wax-cylinder and historical recording metadata belongs in the SRU/archive lane, not a stale Z39.50 profile.
