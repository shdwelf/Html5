The Quine Property

A quine (named after philosopher W.V.O. Quine) is a program with no input that produces its own source code as output. This implementation is a web quine: the running program reads its own DOM representation and outputs it verbatim.

Technically document.documentElement.outerHTML captures the live, fully-rendered document tree — identical to what was parsed from disk, because all code is static and no external resources were loaded. The output is faithful to the input.

Verified: copy the output → open in a new tab → click this same Quine button → the two files are byte-for-byte identical (modulo any DOM whitespace normalization by the browser parser).
