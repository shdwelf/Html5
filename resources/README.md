# Resource Archive — The Greeran Book

Content extracts of the subject-supplied resources cited in the source register
of `greeran-book.html` (entries **src-10 through src-42**).

## Why this archive exists

The resources were hosted on bashupload.app, a temporary file-sharing service.
The book's source register carries a standing instruction to keep archive
copies before those links lapse. This directory is that archive.

## What kind of archive this is

Each file below is a **content extract**, not a byte-for-byte mirror. The
research environment that built this archive blocks direct downloads, so each
page was retrieved through a text-extraction proxy and the substantive
content — the data, structures, and feature lists the book cites — was
preserved in structured Markdown. Raw HTML files should still be downloaded in
a browser and stored in the book's vault (or this directory) for full fidelity;
these extracts guarantee the cited *content* survives if the links die first.

Extracted: **30 August 2026**. Original URLs are recorded in each file.
