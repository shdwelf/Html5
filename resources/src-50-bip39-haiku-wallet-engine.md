# BIP-39 Haiku Wallet Engine

> **Register:** src-50 · **Original:** https://bashupload.app/ya0iaz.htm
> **Extracted:** 30 August 2026 · **Type:** self-published standalone HTML5 tool

The second-generation haiku miner (cf. src-40 and src-16/20's haiku workbench material).

## Engine features

- **Paste the 2048-word dictionary once** — saved to localStorage; fully offline thereafter
- **AES-256-GCM encrypted wallet vault** behind a master password
- **Grammar heuristics** — rejects awkward poetic line-breaks
- **Mine Poetic Wallet** — grinding mnemonics that are both valid and poetic
- **Export Secure .TXT**
- **Purge wordlist** (full local-dictionary wipe)
