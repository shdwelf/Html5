# HTML5 Offline ZIP Audit & Repair Viewer

> **Register:** src-49 · **Original:** https://bashupload.app/qkhr0t.htm
> **Extracted:** 30 August 2026 · **Type:** self-published standalone HTML5 tool

The quality-control companion to the ViteReact build suite (src-47/48).

## Audit & repair workflow

- Loads a workspace/project ZIP
- **Audits:** HTML5 doctype · charset · viewport · title · external dependencies ·
  offline blockers · inline-repair potential
- Previews the detected entry point
- Downloads a **repaired standalone HTML** with internal assets inlined as data URLs

*(Companion QC tool for the same inlined/.xdc pipeline this repository uses for
the book's own editions.)*
