# Rodger Ramrod — HTML5 App (quine build)

> **Register:** src-63 · **Original:** https://bashupload.app/u891yp.htm
> **Extracted:** 30 August 2026 · **Type:** self-published standalone HTML5 wrapper (software preservation)

A second build of the Rodger Ramrod browser-DOSBox wrapper (src-62). Identical metadata,
manifest, and conversion path; the difference is in what the page offers the visitor.

## What changed from src-62

- The download control is relabelled **Download Quine (.HTML)** (src-62: "Download App (Quine)")
- A **"What is a Quine?"** explainer is now linked inline
- The footer states the property explicitly:

  > "This is a single-file HTML5 app: all JS, CSS, and assets are inlined into one index.html.
  > The Quine button downloads the running page itself — save it, open it anywhere, no server
  > required."

## Why it is filed separately

The quine is the recurring signature of this workshop rather than a feature of this one page:
the GEDCOM converter (src-19), the ACME workstation (src-29), the WebTools Hub (src-51,
src-52), and now this preservation wrapper all ship a button that makes the page emit its own
source. Two builds of the same app, 22 links apart, is the workshop iterating in public — the
same habit that produced two WebTools Hub builds thirty-four seconds apart.

See also: src-62 for the metadata, package manifest, and conversion path, which are unchanged.
