SNEAKERS

COMPUTER PRESS KIT · 1992

“My voice is my passport. Verify me.”

Boot a locally bundled DOS preview of the film’s promotional press kit. The emulator and its game bundle are stored inside this Webxdc and make no network requests.

Preservation note: the bundled program is a repository-built reconstruction, not a byte-for-byte copy of the original Archive.org floppy or ZIP.
Keyboard: enter setec astronomy at the access prompt, then use the menu keys.
Mouse: click the display once to hand the pointer to DOSBox — clicks and keys reach the game only while the display has focus.
Touch: open js-dos’ ☰ sidebar for its on-screen keyboard.
READY · press BOOT to start the offline DOS session
About · controls · provenance

What this is. An offline Webxdc shell around the repository’s compact SNEAKERS.jsdos bundle, using js-dos 8.4.1 (DOSBox compiled to WebAssembly). Press BOOT, type setec astronomy at the password prompt, then choose a menu option with the keyboard.

What it is not. The original item contains a 1.44 MB floppy image and a larger distribution ZIP. This package does not include those original files: its DOS program and companion assets are a locally reconstructed, browser-ready subset. The reconstruction should not be presented as a verified byte-identical preservation copy.
