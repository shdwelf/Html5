Create a new command

Mirrors yubnub.org/command/new: ① pick an unused name ② paste a URL with %s (or ${switch=default} — see Advanced syntax) ③ test it ④ describe it. Here your command is saved locally in the app (and can be shared to the chat); it is not posted to yubnub.org.

Advanced syntax — condensed from yubnub.org/documentation/describe_advanced_syntax, all of it implemented in this app

%s — the argument

Template http://images.google.com/images?q=%s + gim porsche 911 → …?q=porsche+911. Spaces become +; other characters are URL-encoded (Mork & Mindy → Mork+%26+Mindy).

${switch} and ${switch=default} — multiple parameters

Template …?q=${what}&near=${where=Washington, DC} + gloc -what pizza -where Poughkeepsie, NY. Dashes are a tribute to command-line heritage — -what is the “what switch”.

{ nested commands } — pipes

g {random 100}, gloc -what {% 1 %s} -where {% 2 %s}[no url encoding]. Braces are evaluated innermost-first; a nested command's text output (or its URL, via url) is spliced in.

Directives (stripped from the final URL)

[no url encoding] — e.g. Wayback: http://web.archive.org/web/*/%s[no url encoding]
[use %20 for spaces] / [use - for spaces] — pick the space character.
[post] — GET→POST forms (Sean O'Hagan's get2post). This app flags it and shows the URL; it cannot POST-redirect offline.

Commands that make commands

url gim porsche 911 returns the URL instead of going there · % 2- one two three extracts tokens (CUT-style ranges: N, N-, N-M, -M) · strReplace -find a -replace o -string Banana · ifThen -value1 … -test EQUAL -then … -else … · switch: { switch ${plat} | xbox => 13, * => 0 }. echo, random, %, strReplace, strFind, strLength, ucase/lcase, ifThen, ifEmpty, explode, date all run locally, offline in this rebuild.

Installing Yubnub (the 2005 way, still true)

Add a custom search engine / keyword with the URL http://yubnub.org/parser/parse?command=%s — or point it at this app hosted anywhere: …/yubnub.html?command=%s (the app auto-runs ?command=). Full per-browser history (Firefox search plugin, IE registry file, Safari Sogudi, Opera, Konqueror \{@}, LaunchBar, Conkeror…) is archived in the Link crawl tab and yubnub-deep-dive.md.
