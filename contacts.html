Postal, ISO, NIH, and Stamps.com data notes

USPS ZIP data

No USPS reference list is bundled. This app preserves postal codes exactly as imported or typed and does not validate them. USPS has monthly official products and an online, authenticated address API; their data terms are not an open-data grant. Use only an authorized file or service for your intended use.

ISO country codes

The country-code field is optional text, not an ISO validator. ISO's Online Browsing Platform is the live reference; its integrated Country Codes Collection includes current and formerly used codes. Import a snapshot only if its terms permit your use.

NIH sources

There is no general NIH historical contact feed in this app. NIH RePORTER is for funded projects and organizations; NIH facility-address pages cover campuses; NLM's NPI search reflects CMS/NPPES provider data. Choose the exact source before importing.

Stamps.com

Stamps.com provides an online shipping/address-validation API, not a standalone ZIP directory. It is not connected here: a live validation request would leave this device and can require an account and credentials.
