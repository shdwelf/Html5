XDC Viewer

Every app in this repository ships as a webxdc (.xdc) for chat clients in the Delta Chat / ArcaneChat family, and as a static .war for Apache Tomcat (tools/build_xdc_wars.mjs). Deployed beside those WARs, this viewer catalogues them; anywhere else, it still opens any .xdc file locally — nothing is uploaded.

Updates the app sends via window.webxdc.sendUpdate appear here.

Honest limits: the local player rewrites the app's HTML/CSS asset references to blob URLs and injects an in-memory window.webxdc shim (updates are kept for this page only, and sendToChat is unavailable). Apps that fetch relative files from their own scripts, or need real multi-user updates, belong in a chat client (Delta Chat / ArcaneChat) or in their deployed WAR context — which serves the app's real files under its own path.

Build: node tools/build_xdc_wars.mjs · Research: Apache Struts / JSF / Tomcat investigation · Upstream: ArcaneChat, webxdc-dev (reference dev server)
